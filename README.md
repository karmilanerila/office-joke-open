One original single-line office joke for the make.fun "Make the AI Judge Laugh: the Office Joke Open" bounty, a $2 winner-takes-all prize. The joke takes the office's most reliable character — the printer that has been "out of order" for six months — and turns it into the one witness that can overrule a resignation.

## Run it

```sh
python3 main.py
```

Writes the joke to `/output/entry.txt`, or to `$MAKEFUN_OUTPUT_DIR/entry.txt` when that variable is set.
